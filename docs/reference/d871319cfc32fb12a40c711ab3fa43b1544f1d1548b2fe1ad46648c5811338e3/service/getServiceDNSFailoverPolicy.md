# Get the canonical DNS failover policy

`GET /api/v1/services/project/{serviceId}/environments/{environmentId}/domains/{domainId}/dns/failover-policy` · `getServiceDNSFailoverPolicy` · Service

## Behavior and lifecycle

Returns the disabled, operator-approved, or automatic-external policy together with bounded thresholds, TTL, cooldown, attempt limit, and approved distinct-Worker targets.

- Automatic-external mode creates fenced plans but still delegates provider mutation to the external agent.
