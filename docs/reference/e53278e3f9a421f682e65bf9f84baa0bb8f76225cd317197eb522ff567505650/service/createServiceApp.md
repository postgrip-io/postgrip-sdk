# Create a service application grouping

`POST /api/v1/services/apps` · `createServiceApp` · Service

> Contract bundle `e53278e3f9a421f682e65bf9f84baa0bb8f76225cd317197eb522ff567505650`
> Service contract `08309318d5a9624cb4447f01417077eed5c1f0d21f02bcfe8c9c6f386ccd8a30`

## Behavior and lifecycle

Creates one tenant-scoped application grouping after fencing the Service catalog ETag.

- Supply the ETag returned by listServiceApps as If-Match.
- Idempotency: required.
- Use isolated fixtures and clean up recorded resource identifiers.

## cURL

Requires cURL 7.76 or newer. The bearer is supplied over standard input and does not enter the process argument list.

