# List declarative configuration plan actions

`GET /api/v1/services/configuration-stacks/{stackKey}/plans/{planId}/actions` · `listPostGripConfigurationPlanActions` · Service

> Contract bundle `eb5a6a016b1efa62f0f720847888fc31575c5b7c797a6d5b4814bfbba07ccd1d`
> Service contract `74d48490b3cf7b7fc4962124d2d5a9a0432dcf384e6ec4b877872118a9f2044b`

## Behavior and lifecycle

Returns one bounded, cursor-paginated page of deterministic safe plan actions. Projections include resource ETags and redacted secret input metadata, never resolved secret bytes.

- Follow nextCursor until it is empty to consume the complete action graph.

## cURL

Requires cURL 7.76 or newer. The bearer is supplied over standard input and does not enter the process argument list.

```sh
set +x
POSTGRIP_API_URL="${POSTGRIP_SERVICE_URL:-${POSTGRIP_URL}}"
: "${POSTGRIP_API_URL:?set POSTGRIP_URL or the plane-specific URL}"
: "${POSTGRIP_TOKEN:?set POSTGRIP_TOKEN}"
: "${POSTGRIP_STACK_KEY:?set POSTGRIP_STACK_KEY to a percent-encoded path value}"
: "${POSTGRIP_PLAN_ID:?set POSTGRIP_PLAN_ID to a percent-encoded path value}"
curl \
  --config \
  - \
  --fail-with-body \
  --silent \
  --show-error \
  --request \
  GET \
  "${POSTGRIP_API_URL}/api/v1/services/configuration-stacks/${POSTGRIP_STACK_KEY}/plans/${POSTGRIP_PLAN_ID}/actions" <<EOF
header = "Authorization: Bearer ${POSTGRIP_TOKEN}"
EOF
```
