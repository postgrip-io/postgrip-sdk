# PostGrip SDKs

`POSTGRIP_TOKEN`.

- [TypeScript SDK](https://postgrip-io.github.io/postgrip-sdks/typescript/)
- [Python SDK](https://postgrip-io.github.io/postgrip-sdks/python/)

- [Authentication](authentication.md)
- [Configuration](configuration.md)

embedded in all generated clients.
