    Limits and open gaps

    No deployment or live SDK operation was exercised for this documentation task. Recorded endpoint coverage and live-tier ownership are not live success evidence. The existing Python live smoke skip and scheduled production-smoke failures do not become passing results because documentation CI is green.

    SDK CI still runs full validation on Markdown changes, uses GitHub-hosted runners, and lacks web's action pinning, timeout and main-run cancellation policies. Its current CI owner records those gaps. No workflow behavior was changed. Enabling squash merges was the only repository-setting change and was explicitly approved. Web's SDK source pin, contract bytes and compatibility Go import path remain unchanged.

    Example launchers retain legacy override readers and pinned remote bootstrap commands. Their READMEs now distinguish those from current SDK configuration; the Python launcher still assumes an old archive directory name. This cleanup corrects and documents usage and limitations, not the live launcher implementation.
