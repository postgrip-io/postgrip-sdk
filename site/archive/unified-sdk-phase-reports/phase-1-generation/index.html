    Deviations and corrective actions

    The synchronized public Agent contract no longer contains the server-global compact operation, but compatibility tests and handwritten TypeScript/Python facades still referenced it. This was an implementation defect relative to the Phase 0 global-admin separation. The method, aliases, and expectations were removed in all languages and all cumulative suites were rerun successfully.

    The first drift-check run still classified CompactRequest and CompactResponse as public OpenAPI-owned protocol models. Their ownership entries were removed from the public generator while the server may continue to use its internal admin contract. The drift check then passed.

    The Phase 2 import audit found that two design examples still used the placeholder pg_ token prefix and a Go module path that conflicted with the repository's explicit compatibility constraint. The normative examples now use pgt_ and retain github.com/postgrip-io/postgrip-agent-sdks/go. Phase 0 authentication and Phase 1 generation were rerun because the correction affected their recorded design revision; both remained green.

    No unresolved Phase 1 deviations remain.

    Remaining risks

    • Package consolidation has not happened yet; the generated files still live in the three current artifact roots. Phase 2 moves them once and removes the old roots, so this is sequenced work rather than a duplicate source tree.
    • Registry ownership and coordinated server deployment remain the release risks recorded in Phase 0.
